# Security Policy

## Supported versions

Security fixes are made for the latest published version of `@flowstack-ui/theme`.
Older releases may be affected even when a fix is available in the current
release.

## Report a vulnerability

Do not open a public issue. Submit a
[private security advisory](https://github.com/flowstack-ui/theme/security/advisories/new)
with:

- the affected package version and import path;
- the security impact and realistic attack scenario;
- a minimal reproduction or proof of concept;
- relevant runtime, browser, and build-tool versions; and
- any suggested remediation or disclosure constraints.

Remove credentials, tokens, private user data, and other unrelated secrets from
the report. Maintainers will acknowledge the report, validate its impact,
coordinate a fix and release when needed, and discuss disclosure and credit
with the reporter.

## Scope

In scope are vulnerabilities in the published package, including theme contracts, public package entry points, and packaged styles.
Documentation mistakes without security impact, unsupported versions,
third-party services, and findings produced only by an automated scanner
without a credible impact or reproduction are generally out of scope.
