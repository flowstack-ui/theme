# Contributing

Thanks for contributing to `@flowstack-ui/theme`.

## Before opening an issue

- Search existing issues first.
- Use the bug form for a reproducible package problem.
- Use the feature form for a new public capability or contract.
- Report vulnerabilities privately according to [SECURITY.md](SECURITY.md).

## Pull requests

Keep changes focused, preserve the package's public theme and token contracts,
and follow the setup and verification commands in the README and package
scripts. Update tests, documentation, generated artifacts, and the changelog
when the public contract changes.

By participating, you agree to follow the
[Code of Conduct](CODE_OF_CONDUCT.md).
